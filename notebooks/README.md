# notebooks/ — finished Kaggle runs, one folder per member

Every notebook here is the **finished** run downloaded from Kaggle (all cells run, outputs kept), so anyone can see
exactly what was trained and printed. The empty notebook you run yourself is in [`src/`](../src/).

**Name:** `notebooks/<Member>/paperNN_run.ipynb` (two-digit paper number). The Kaggle log of the same run, if you
keep it, is `paperNN_run.log`.
