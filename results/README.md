# results/ — the team results table

| File | What it is |
|---|---|
| [`results_table.md`](results_table.md) | For each paper with results: our numbers next to the paper's, then tables that compare all members' detectors and plate readers |
| [`experiments.csv`](experiments.csv) | The same data, one row per trained model (or per number reported in a paper): member, data, epochs, mAP, OCR accuracy, speed, training time |

Both files are generated by `add_results.py` (in Rokib's local kit) from each paper's `paperNN_outputs.zip`.
They now cover papers **02, 03, 06, 08, 23 and 24**.

**Rules of the table**

- Numbers measured on different data are not comparable. Paper numbers measured on the paper's own data are kept apart.
- Plate readers are only ranked against runs on the same dataset version (v1.0 or v1.1).
- To add your paper, upload your results (see [CONTRIBUTING.md](../CONTRIBUTING.md)) and ask Rokib to run
  `add_results.py` on your `paperNN_outputs.zip`. Do not edit these two files by hand.
